## 已实现的范围

- 首页和房间每次打开倍率输入框均为空；示例不再显示 0.3。仍保留主动输入的积分倍率，范围 (0, 1000]，不代表现金兑换。
- 首页、创建、加入、房间、明细、汇总和个人页显示娱乐用途提醒。
- 隐私说明与用户使用约定、未勾选的明确同意、撤回入口、联系/举报邮箱。
- 同意之前不调用云登录或读取牌局；同意后恢复原邀请页面；旧缓存不再用于新版本展示。
- 头像可由用户通过微信头像控件主动选择并上传，服务端只接受当前用户 `avatars/<openid>/` 路径下的云文件；昵称经微信昵称控件或手动输入后提交内容安全检查。review、risky 或接口故障均拒绝。
- getTable、写入和二维码生成检查成员身份；非成员只能凭邀请查看最小预览；加入需要匹配分享码、牌局未结束、最多 8 人。新邀请使用 20 位加密随机码，兼容已有 6 位码。
- 隐藏其他成员真实 openid；保留自己的 openid 供现有客户端权限 UI 使用。敏感权限判断只在服务端进行。
- 数据库改为服务端读写，前端每 5 秒通过云函数同步。与直接 watch 相比有同步延迟和额外调用成本。
- 服务端持久化限流：一般接口每用户每分钟 120 次；邀请查询、加入、修改昵称各 20 次；建桌 5 次；二维码 10 秒最多一次。
- 修改牌局采用事务与 revision 检查；下一局创建采用事务，避免重复创建。
- 个人数据删除可中断恢复：扫描身份及旧头像引用、清理跨局摘要和通知、移除本人关联、转交桌主或删除无人牌局、删除已追踪头像；只有云存储明确返回成功的文件才会从待删队列移除，完成后撤回本机同意。
- 固定现有 wx-server-sdk 为 4.0.2，没有新增第三方依赖；二维码默认 release，测试环境可配置 trial。
- 数据库导出、测试、脚本和文档不进入小程序上传包；数据库导出文件目前仍保留本机及既有 Git 历史，未擅自销毁。

## 必须按顺序完成的云端部署（尚未执行）

1. 备份现有云端数据，先在隔离测试云环境验证。现有 AppID/环境 ID 没有更换，请确认环境归属和实际区域。
2. 创建集合：`tables`（已有）、`request_limits`、`privacy_jobs`、`privacy_locks`、`legacy_avatar_files`。
3. 上述所有集合的客户端安全规则均设置为 `config/database.rules.json`：read=false、write=false。配置文件不会自动部署，请在云控制台逐个应用。
4. 云存储客户端规则使用 `config/storage.rules.json`：允许头像控件产生的客户端上传，禁止客户端读取；服务端只接受当前用户头像路径并负责临时 URL 展示和旧文件删除。检查历史文件公开访问设置，已发出的临时链接可能在过期前仍有效。
5. `request_limits.expiresAt` 配置 TTL 索引（如环境支持）或每日定时清理；不要自动清理未完成的 `privacy_jobs`，它们支持断点续删。privacy_locks 的租约为120秒。
6. 上传部署 login、tableOps、tableCode，并选择云端安装依赖。tableOps 需连同 safety.js 和 config.json 部署，后者声明 security.msgSecCheck；tableCode 声明 wxacode.getUnlimited。
7. tableOps 超时配置为60秒（必须小于删除任务锁120秒）；验证事务与嵌套对象更新行为。数据删除逐批执行，失败可再点继续。大规模数据需改为受控后台任务，当前不是无限容量的删除作业系统。
8. 建立查询所需索引，以控制台报错建议为准：participantOpenids + createdAt，participantOpenids + groupId + createdAt，shareCode，groupId + ownerOpenid + _id，legacy_avatar_files.ownerOpenid + _id。
9. 上传体验版时，测试云环境 tableCode 设置 `MINIPROGRAM_ENV_VERSION=trial`；上传的体验版必须含 pages/join/join。正式云环境设置 release 或不设该变量；首次正式发布前 release 码可能不可生成，不能为了掩盖问题关闭路径检查。
10. 收紧规则、新云函数与新客户端应协同发布。旧客户端的直读监听和图片上传不再支持，不要单独更新客户端后仍保留宽松权限。

## 验收

本地命令：

```sh
node scripts/check-release.js
node --test tests/*.test.js
```

自动测试使用内存云服务替身，不连接真实数据库，不证明真实审核 API、云权限或手机 UI 已通过。

真机至少用两个受邀用户与一个非成员验证：

1. 清理旧客户端缓存后首次进入：首页及说明可读；未同意不会云登录；拒绝不退出整个小程序。
2. 从邀请首次进入，同意后仍回到原邀请；不选头像可创建/加入；昵称和桌名正常保存。
3. 测试环境验证内容安全正常/拒绝/接口不可用；只在通过时保存。不要把违规测试内容发布给无关用户。
4. 非成员通过 ID 读取、静音、给分、生成二维码应被拒绝；通过分享码只能看最小预览；已结束牌局不能新增成员。
5. 成员并发给分、撤销、改名及下一局；重复开启下一局不产生两桌；汇总空倍率被拒绝，手动输入合法倍率可用。
6. 控制台模拟客户端直读数据库、上传/读取云存储均应拒绝；云函数计分仍可运行。
7. 删除数据前后核对 tables、privacy_jobs、privacy_locks 和云存储；中途中断后再次继续；原 openid 不再拥有成员访问权；其他成员积分不改变。
8. 全部历史局中的昵称、结算快照、通知、ownerOpenid、participantOpenids、operatorOpenid 和头像引用均核对。其他成员缓存或截图不等于云端副本，不能承诺删除外部截图。
9. 体验与正式二维码分别对应正确版本；正式发布后用非体验成员扫码验收。
10. 在开发者工具检查实际上传包文件清单无 database_export、tests、scripts、docs；确认所有页面提示不遮挡输入与按钮。
